# 📋 Lista de Tarefas

Aplicação web simples para gerenciamento de tarefas desenvolvida com Laravel.
Nesta aplicação os usuários podem se registrar, fazer login, criar, editar, concluir e excluir suas tarefas.

## 🛠 Tecnologias Utilizadas

- Laravel 12
- Blade (Template Engine)
- Bootstrap 5
- MySQL ou SQLite
- Composer

## 🚀 Funcionalidades

- Registro e login de usuários
- Criação, edição e exclusão de tarefas
- Marcar tarefas como concluídas
- Interface amigável com mensagens
- Apenas usuários autenticados podem gerenciar tarefas

## ⚙️ Como Rodar o Projeto

### 🔧 Pré-requisitos

- PHP >= 8.1
- Composer
- MySQL ou SQLite
- Node.js e npm
